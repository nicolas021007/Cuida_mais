# clinica_API

API REST  para gerenciamento de uma clinica médica, desenvolvida com **FastApi** e **Python**. Permite o cadastro de  doutores e pacientes.

---

## Baixar a API FASTAPI

baixar primeiro o venv

1. criação de ambiente virtual 
python3 -m venv venv

2. Ativar o ambiente virtual
source venv/bin/activate

3. Instalar o FASTAPI
